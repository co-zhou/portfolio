# Math Expression Solver

A calculator that evaluates mathematical expressions written in infix notation. It converts the expression to postfix notation using a stack of operators, then evaluates the postfix expression using a second stack of integers.

The program supports the basic operators (`+`, `-`, `*`, `/`), single-digit integers, and parentheses. Every operation must be parenthesized, e.g. `((4*(3+2))-(8/4))` = `18`.

## Run

`./evalPostfix`
