# Supervised Learning

A comparison of six supervised learning models using scikit-learn to predict a Pokémon's identity from its stats (HP, attack, defense, etc.).

The models compared are K-Nearest Neighbors, Linear Discriminant Analysis, Gaussian Naive Bayes, Decision Tree, Support Vector Machine, and a Multi-Layer Perceptron neural network. Each model is trained on the same data, evaluated on validation data, and its confusion matrix is saved for comparison.

## Run

`python Classifier.py`
