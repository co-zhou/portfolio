# Python Projects

Artificial intelligence and machine learning projects using Python. Several projects implement algorithms from scratch (no ML libraries) to demonstrate a deep understanding of how the methods work, while others use scikit-learn and Keras/TensorFlow to apply modern ML techniques to real data. Application areas include silicon wafer defect detection, stock price forecasting, and design/test automation for electronic design automation (EDA).
